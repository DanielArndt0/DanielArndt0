## Projetos em destaque

### [CNPJ DB Loader](https://github.com/DanielArndt0/cnpj-db-loader)

CLI que baixa, prepara e importa os dados públicos de CNPJ da Receita Federal para o PostgreSQL.

Ele faz o caminho inteiro até a base ficar utilizável: download, extração, validação, sanitização, geração do schema e importação de um volume grande de registros. A ideia é que uma aplicação que dependa desses dados já comece de uma base organizada.

### [CNPJ API](https://github.com/DanielArndt0/cnpj-api)

API REST que acompanha o CNPJ DB Loader. Um prepara e importa a base; o outro expõe os dados para consulta por aplicações, integrações, dashboards e automações.

### [Email Marketing](https://github.com/DanielArndt0/email-marketing)

Sistema para gerenciar campanhas, listas de contatos e o processamento de envios de email. Foi onde explorei filas, processamento assíncrono e a infraestrutura necessária para enviar em escala.

### [Brutils](https://github.com/DanielArndt0/brutils)

CLI em Node.js e TypeScript com utilitários para as tarefas que aparecem toda semana: validar e manipular CPF, CNPJ e CEP, trabalhar com JSON, gerar hashes, UUIDs e tokens, lidar com datas, strings e arquivos ZIP.

### [PyDF](https://github.com/DanielArndt0/pydf)

Biblioteca Python e CLI para ler e processar PDFs. Extrai informações de forma estruturada, exporta para Excel e, quando é o caso, grava em banco de dados.
