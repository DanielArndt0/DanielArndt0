* [CNPJ API](https://github.com/DanielArndt0/cnpj-api): API REST para consultar os dados preparados pelo loader.
* [Brutils](https://github.com/DanielArndt0/brutils): utilitários de terminal para validação, formatação e manipulação de dados, publicados no npm.
* [Email Marketing](https://github.com/DanielArndt0/email-marketing): sistema de campanhas com filas e processamento assíncrono de envios.
* [PyDF](https://github.com/DanielArndt0/pydf): biblioteca e CLI Python para extração de dados de PDFs e exportação para Excel.
* [Matterbloom](https://github.com/DanielArndt0/matterbloom): sandbox científico 2D em C++, com simulação de materiais e interações físicas.

## Ferramentas para Windows

Scripts para personalizar o menu de contexto do Windows 10 e 11. Cada projeto inclui instalação e remoção, sem exigir privilégios de administrador.

* [VS Code Context Menu](https://github.com/DanielArndt0/vscode-context-menu-windows): adiciona a opção **Open with VS Code** para arquivos, pastas e o fundo de diretórios.
* [CMD Context Menu](https://github.com/DanielArndt0/cmd-context-menu-windows): adiciona **Open CMD here** para abrir o Prompt de Comando na pasta selecionada.
* [PowerShell Context Menu](https://github.com/DanielArndt0/powershell-context-menu-windows): adiciona **Open PowerShell here** diretamente pelo Explorador de Arquivos.

## Sistemas embarcados

Projetos práticos com ESP32, PIC e Arduino, voltados a comunicação, periféricos e experimentação com hardware.

* [ESP32 AWS IoT](https://github.com/DanielArndt0/esp32-aws-iot): comunicação MQTT com AWS IoT Core usando TLS e certificados X.509.
* [ESP32 Gemini IoT](https://github.com/DanielArndt0/esp32-gemini-iot): integração de ESP32 com API Gemini e exibição de respostas em display OLED.
* [PIC UART](https://github.com/DanielArndt0/pic-uart): exemplo de comunicação serial USART no PIC16F877A.
* [PIC Timer](https://github.com/DanielArndt0/pic-timer): exemplo de Timer0 e interrupções no PIC16F628A.
* [Intervalômetro](https://github.com/DanielArndt0/intervalometro): controlador de disparos para câmeras DSLR com Arduino Nano e display OLED.
