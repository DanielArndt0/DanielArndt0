## Projetos em destaque

### [CNPJ DB Loader](https://github.com/DanielArndt0/cnpj-db-loader)

CLI para baixar, preparar e importar os dados públicos de CNPJ da Receita Federal para PostgreSQL.

O projeto executa o fluxo de preparação da base, incluindo **download, extração, validação, sanitização, geração de schema e importação de grandes volumes de dados**, servindo como base para aplicações que precisam trabalhar com esses dados de forma estruturada.

### [CNPJ API](https://github.com/DanielArndt0/cnpj-api)

API REST desenvolvida como **complemento ao CNPJ DB Loader**.

Enquanto o CNPJ DB Loader é responsável pela preparação e importação dos dados para PostgreSQL, a CNPJ API fornece a camada de **consulta e exposição desses dados**, permitindo sua utilização por aplicações, integrações, dashboards e automações.

### [Email Marketing](https://github.com/DanielArndt0/email-marketing)

Sistema voltado ao gerenciamento de **campanhas, listas de contatos e processamento de envios de email**, explorando a arquitetura necessária para organizar e executar fluxos de comunicação em escala.

O projeto também serve como referência para estudos e desenvolvimento de serviços relacionados a filas, processamento assíncrono e infraestrutura de envio.

### [Brutils](https://github.com/DanielArndt0/brutils)

CLI em Node.js e TypeScript que reúne utilitários para tarefas recorrentes de desenvolvimento.

Inclui ferramentas para validação e manipulação de **CPF, CNPJ, CEP, JSON, hashes, UUIDs, tokens, datas, strings e arquivos ZIP**, entre outros recursos.

### [PyDF](https://github.com/DanielArndt0/pydf)

Biblioteca Python e CLI para leitura e processamento de documentos PDF, permitindo **extração estruturada de informações, exportação para Excel e persistência opcional em banco de dados**.

## Labs e experimentos

Também mantenho projetos voltados a **estudo, experimentação e exploração de outras plataformas e áreas da computação**, incluindo desenvolvimento mobile, sistemas embarcados, microcontroladores e redes.

* **[Talkio](https://github.com/DanielArndt0/Talkio)** — aplicativo de mensagens em tempo real com chats individuais, notificações, indicadores de digitação e atualização das conversas em tempo real.

* **[landmarks-swiftui](https://github.com/DanielArndt0/landmarks-swiftui)** — projeto de estudo de **Swift e SwiftUI**, explorando navegação, gerenciamento de estado, carregamento de dados locais, MapKit e construção de componentes reutilizáveis.

* **[SimpleOS](https://github.com/DanielArndt0/SimpleOS)** — projeto experimental voltado à exploração de arquitetura de sistemas operacionais e software para microcontroladores.

* **[embedded-gemini-client-demo](https://github.com/DanielArndt0/embedded-gemini-client-demo)** — experimento de integração entre sistemas embarcados e serviços externos utilizando ESP32 e display OLED.

* **[pic-eeprom-library](https://github.com/DanielArndt0/pic-eeprom-library)** — estudo de sistemas embarcados com rotinas reutilizáveis de leitura e escrita da memória EEPROM interna de microcontroladores PIC.

* **[esp32-ssid-spammer](https://github.com/DanielArndt0/esp32-ssid-spammer)** — estudo experimental sobre **Wi-Fi, beacon frames e comunicação 802.11** utilizando ESP32 em ambiente controlado.
