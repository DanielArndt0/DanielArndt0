# **Daniel Arndt**

Desenvolvo aplicações web, APIs, integrações e automações. Atualmente, atuo na [NDT digital.](https://ndtdigital.com.br), trabalhando com desenvolvimento de sistemas, produtos digitais e infraestrutura de aplicações.

Também mantenho projetos open source e ferramentas próprias. Tenho interesse especial em C++, desenvolvimento de bibliotecas, sistemas embarcados e programação de baixo nível.

## Projetos em destaque

* **[CNPJ DB Loader](https://github.com/DanielArndt0/cnpj-db-loader):** ferramenta CLI para baixar, processar e importar dados públicos de CNPJ da Receita Federal no PostgreSQL.
* **[CNPJ API](https://github.com/DanielArndt0/cnpj-api):** API REST para consulta de dados empresariais, com filtros, paginação e integração com aplicações.
* **[Brutils](https://github.com/DanielArndt0/brutils):** ferramenta CLI com utilitários para CPF, CNPJ, CEP, JSON, strings, hashes e outras operações.
* **[Email Marketing](https://github.com/DanielArndt0/email-marketing):** sistema para gerenciamento de campanhas, contatos e processamento assíncrono de e-mails.
* **[PyDF](https://github.com/DanielArndt0/pydf):** biblioteca e CLI em Python para processamento de PDFs e exportação de dados. Desenvolvido em colaboração com [Davi Arndt](https://github.com/daviarndt).
* **[Matterbloom](https://github.com/DanielArndt0/matterbloom):** sandbox científico 2D desenvolvido em C++, com simulação de materiais e interações físicas.

## Estudos e desenvolvimento

Gosto de estudar conceitos de programação de baixo nível, estruturas de dados, templates e recursos da linguagem C++. Parte desse interesse está no desenvolvimento de bibliotecas pequenas, reutilizáveis e com poucas dependências.

### Bibliotecas C/C++

Projetos de estudo e experimentação, principalmente em formato header-only e com suporte a C++11 ou superior.

* **[Num](https://github.com/DanielArndt0/num):** wrapper numérico com operadores aritméticos, comparações e conversão para string.
* **[Vector](https://github.com/DanielArndt0/vector):** implementação de array dinâmico com gerenciamento de memória, capacidade e operações de cópia e movimentação.
* **[Duet](https://github.com/DanielArndt0/duet):** estrutura para armazenar pares de valores, com suporte a diferentes tipos.
* **[Same](https://github.com/DanielArndt0/same):** comparação de tipos em tempo de compilação utilizando templates.
* **[Primitive](https://github.com/DanielArndt0/primitive):** identificação de tipos fundamentais da linguagem C++.
* **[Expr](https://github.com/DanielArndt0/expr):** inspeção de tipos em expressões não avaliadas, utilizando `decltype`.
* **[Rref](https://github.com/DanielArndt0/rref):** manipulação de referências rvalue e regras de colapso de referências.
* **[Typestr](https://github.com/DanielArndt0/typestr):** obtenção de nomes de tipos para diagnóstico e experimentação.
* **[Bitkit](https://github.com/DanielArndt0/bitkit):** macros para manipulação de bits, máscaras, deslocamentos e extração de bytes em C e C++.

### Outros projetos

Entre meus projetos de estudo está o [SimpleOS](https://github.com/DanielArndt0/SimpleOS), um sistema experimental desenvolvido em C++ para o microcontrolador ATmega328P, explorando gerenciamento de execução, memória e comunicação com periféricos.

## Sistemas embarcados

Tenho interesse em eletrônica, microcontroladores e desenvolvimento de firmware. Mantenho projetos com ESP32, PIC e Arduino, incluindo exemplos de comunicação, temporizadores, leitura de periféricos e integração com serviços externos.

* **[ESP32 AWS IoT](https://github.com/DanielArndt0/esp32-aws-iot):** comunicação MQTT segura com AWS IoT Core utilizando certificados X.509.
* **[ESP32 Gemini IoT](https://github.com/DanielArndt0/esp32-gemini-iot):** integração com a API do Google Gemini e display OLED, desenvolvida para meu canal [Lab Embarcado](https://www.youtube.com/@LabEmbarcado).
* **[PIC UART](https://github.com/DanielArndt0/pic-uart):** comunicação serial USART no PIC16F877A.
* **[PIC Timer](https://github.com/DanielArndt0/pic-timer):** utilização do Timer0 e interrupções no PIC16F628A.
* **[PIC Analog Read](https://github.com/DanielArndt0/pic-analog-read):** leitura de entradas analógicas com conversor ADC no PIC16F877A.
* **[PIC EEPROM](https://github.com/DanielArndt0/pic-eeprom):** leitura e escrita na EEPROM dos microcontroladores PIC12F629 e PIC12F675.
* **[PIC Pulse Generator](https://github.com/DanielArndt0/pic-pulse-generator):** gerador de pulsos com PIC16F648A e displays de sete segmentos.
* **[Intervalômetro](https://github.com/DanielArndt0/intervalometro):** controlador para câmeras DSLR com Arduino Nano, potenciômetro e display OLED.
* **[ESP32 SSID Spammer](https://github.com/DanielArndt0/esp32-ssid-spammer):** estudo experimental sobre quadros beacon e comunicação Wi-Fi em ambiente controlado.
